01

GRID · 统一视觉生成

阿里达摩院 · 2024
把"时序生成"重构成"空间网格布局"，用一个模型统一所有视觉生成任务。
问题
图像 / 视频 / 3D 的生成与编辑各自为战——单任务单模型，知识无法共享、参数冗余。而视频方案要么把图像模型当单帧生成器再外挂时序模块，要么从头训视频 DiT，需要海量数据与超高算力。
做法
基于 Flux，把视频帧 / 多视图按 m×n 网格排布，时序生成变成标准化的网格空间操作。不改基座架构，把自注意力拆成帧内注意力 + 帧间注意力，文本-图像交叉注意力为所有帧提供统一约束、支持全帧并行生成。训练用 base loss 保外观布局 + flow loss 学时序动作；推理时把视频生成 / 编辑 / 插帧统一成 inpainting 问题。
亮点
单模型统一支撑图像生成、视频生成、图像编辑、多视图生成、图像理解，打破任务边界，且完全复用图像基座的能力与算力。

寻光 Edit & LuminaIp · 统一编辑与重光照

阿里达摩院 · 业务落地
GRID 框架的能力复用：不训练独立模型，直接支撑 30+ 编辑任务与重光照场景。
问题
业务需要通用且稳定的多任务图像编辑；重光照场景普遍存在细节丢失、纹理失真、光照不合理，且光照编辑与属性保持相互冲突。
做法
编辑侧构建 6M grounding 数据 + 10M 编辑样本及自研水印生成策略；重光照侧提出 LuminaIp，融合 inpainting 的细节保持与 relighting 的光照迁移，构建 LuminaDATA 多源数据集（合成 + 3D 渲染 + 真实采集光照 + 海量 inpainting）。
亮点
支持路人去除、服装上身、去水印、文字重绘等 30+ 编辑任务，落地电商与手机影像；重光照在属性一致性、光照合理性、整体画质上全面优于 IC-Light 等方案。

CanonSwap · 高保真一致视频生成

ICCV 2025
用"规范空间调制"把身份保持和视角/光照变换解耦开。
问题
视频生成 / 人脸交换存在三大难题：身份漂移、时序闪烁、细节丢失。传统方法无法同时兼顾身份一致性、时序连续性与纹理保留，结果易出现帧间跳变。
做法
引入规范空间调制机制，融合图像修复先验，把任务拆解成规范空间特征保持 + 视角 / 光照变换两个独立步骤，从根源上消除身份漂移与时序闪烁。
亮点
身份一致、时序连续、纹理细节同时保住，显著优于既有方案。

PERSIST · 持久 3D 状态世界模型

微软亚洲研究院 · 2025
给世界模型一个"显式、可演化、持久"的 3D 状态，而不是只靠像素记忆。
问题
现有交互式世界模型高度依赖像素历史、没有显式 3D 表示：几何一致性只能隐式学，空间记忆受限于短时序窗口，一回头 / 一转向场景就崩坏；无法建模视角外的物体交互；关键帧检索方案在拓展新区域时质量急剧下降。
做法
在类 Minecraft 体素环境中，把世界建模解耦为3D 环境演化 + 相机预测 + 渲染三个模块，全程维护一个可动态更新的全局持久 latent 3D 状态。自回归流程：单帧初始化 → 以智能体为中心去噪 3D 环境 → 预测相机参数 → 3D 世界投影到相机平面 → 用 3D 信息引导像素去噪出画面。
亮点
可生成数千帧几何与纹理持续一致的交互场景；支持视角外物体交互（碰撞、水淹洞穴等自发演化）；支持生成过程中直接在 3D 空间编辑地形与物体，效果连贯无断层。

WorldCanvas · 具身视频合成

字节 Seed · 2026
只要"一段顶视图 + 一条轨迹"，就能生成多视角、物理合理的机器人交互视频——为具身预训练造数据。
问题
已有方法①依赖强几何先验（要标定相机内外参、要完整参考视频），野外场景无法部署；②任务碎片化，全局视角、腕部视角、深度图各做各的，违背 3D 对极几何；③纯像素拟合没有物理正则，长时序交互出现物体穿透、结构形变、交互逻辑断裂。而高质量多模态交互数据的采集成本极高。
做法
提出统一视觉画布框架，输入极简化为单顶视图视频 + 空间运动轨迹。①语义-运动时空对齐：用 VLM 解析场景布局与物体属性，融合 3D 轨迹与夹爪状态，生成时序对齐的精细 prompt；②网格流匹配统一生成：把全局顶视图、左右腕部视角、深度图整合成 2×2 网格视频，用 DiT + 连续流匹配单步统一生成，隐式学习 3D 对极几何；③物理感知 RL 对齐：设计深度引导的复合奖励（防穿透 + 交互合理性），用 GRPO 优化去噪策略，把物理先验注入生成隐空间。
亮点
生成 49 帧 / 30fps 高保真交互视频，可平滑扩展到 100 帧以上；极端轨迹扰动（反转 / 延伸 / 循环）下任务成功率 87.68%，FVD 降至 179.03、LPIPS 降至 0.2708；实现 10+ 种具身平台零样本跨域生成（RoboTwin 2.0、UMI、人类手部、灵巧手）。

DataClaw · Agentic 多模态数据定制

字节 Seed · 2026
让模型按下游意图，主动把高熵的原始多模态流"精炼"成结构化训练数据。
问题
多模态基础模型的核心瓶颈是高质量训练数据稀缺。物理 / 数字世界产生的原始流（教程视频、具身轨迹、GUI 操作日志）数据熵极高——噪声大、冗余高、结构弱。现有被动标注范式靠启发式规则或通用 VLM，成本高、效果差，挖不出数据里的深层过程逻辑。
做法
提出智能体化数据定制。数据构建走两阶段自动化流程：①轻量领域专家先抽取确定性事实锚点（目标状态、时间边界、OCR、交互事件），解决幻觉与长序列 grounding；②强 VLM 基于锚点做长程逻辑链推理，合成结构化监督数据。训练走 SFT → 规则驱动 GRPO：用确定性规则奖励替代神经奖励模型，优化格式合规、时空锚点一致、推理效率三项。部署支持统一版与领域专家版两种架构。
亮点
数据质量在 Schema 完整性、语义准确性、序列一致性上超越开源 SOTA，语义比肩 GPT-4o / Gemini 而序列一致性更优；同等数据量下，用它定制的数据训练模型，在 GUI 导航、动作视频生成、时空 VQA 上与 Gemini 标注数据持平、部分端到端指标更优，成本大幅下降。覆盖日常生活、教育、具身智能、世界模型 / AIGC、GUI 智能体五大领域。

07

ProSR · 过程塑造的空间推理

空间推理
从"答案正确"升级为"答案正确 + 过程可靠"。
问题
现有范式只以最终答案正确性为目标。我诊断 GRPO 训练过程发现两种典型退化：①伪视觉锚定——把图片抽掉，模型仍能生成几乎一样的推理轨迹和答案，说明它靠的是语言先验和数据集偏差而非视觉证据；②尾部不稳定——推理后期不确定性异常回升，轨迹震荡发散。
做法
把过程缺陷变成可优化的约束。先构建强视觉锚定的空间 CoT 数据（规则过滤：答案正确、长度适中、无重复回溯、空间锚点充足），22K 做 SFT；再在 GRPO 上加两项过程级惩罚：反事实不变性惩罚（同步采样原图与空白图轨迹，惩罚两者熵轨迹过度相似，逼模型真看图）与尾部漂移惩罚（约束后期不确定性相对中期的异常回升），45K 样本上优化。
亮点
5 个复杂空间推理基准平均准确率 69.3%，超当前最优开源模型 3.7 个点。过程指标全面改善：空白图准确率 0.535 → 0.321，后期回升率 0.179 → 0.002，推理尾部几乎无震荡。

ReMoT · 细粒度时空运动推理

CVPR 2026 · Highlight
用"运动对比三元组"逼模型学会分辨相机在动还是物体在动。
问题
时空一致性推理是具身操作、自动驾驶的刚需，但主流 VLM 有根本性缺陷：只擅长静态视觉语义对齐，频繁混淆相机自转与真实物体运动、误判机械爪开合状态、颠倒运动方向。既有方案都是零散修补；而传统训练依赖静态图文对、缺乏细粒度运动监督，纯 SFT 容易训练崩溃、推理冗长、逻辑自相矛盾。
做法
从数据与训练双维度破解。①基于视频结构化元注释（相机 SE(3) 位姿、机器人遥测），用运动估计、三元组构建、VQA 生成三个专家模块，自动生成 16.5K 运动对比三元组——正例与锚点具备真实运动属性，负例视觉高度相似但运动属性相反，强制模型学细粒度判别而非浅层表象。②用准确率 + 逻辑一致性 + 长度正则的复合奖励做 GRPO，并创新采用 SFT 与 GRPO 交替训练，解决单一 SFT 的能力崩溃。
亮点
自建基准整体准确率相对基线 +25.1 个点；在 VLM2、VSI、MMSI 三大权威基准刷新最优；4B 小模型超越 7.5 倍参数的 30B 模型；BLINK / MMStar / MMMU 等通用基准无灾难性遗忘。
09

CoRe · 跨图细粒度对比推理

ACM MM 2026
监督"可验证的中间结构"，而不是只看最终答案。
问题
很多现实任务需要跨多张图比较数量、深度、距离、空间关系，但即便是最强的 VLM 在这类细粒度对比上也系统性出错。更关键的是：只优化答案时，有 17.1% 答对的样本其实伴随着事实错误的推理链——答案对了，过程是蒙的。
做法
①从结构化视觉元数据出发，用多专家协同流水线自动构建 CoRe-20K 三元组训练集（覆盖计数、深度、距离、空间关系），标签可验证、无需人工标注；②提出 TriSR 结构化奖励，在 GRPO 下联合监督属性 grounding、判断对齐、三元组全局一致性；③构建 CoRe-Bench 专用基准。
亮点
在 CoRe-Bench 上大幅超越现有 VLM，部分准确率较最强基线 +28.2 个点，同时在标准多模态基准上保持竞争力。核心结论：利用可验证的中间结构做监督，比只看结果有效得多。

X2Action AnyContext → Action

让机器人的动作，能够 condition 在任意模态、任意长度、任意来源的上下文上。
核心判断：智能的上限，取决于模型能吸收多少上下文。
语言侧——从短 prompt 走向长上下文 + In-Context Learning，LLM 的能力随上下文丰富度不断涌现； 视频生成侧——标注越详细，可控生成越贴意图； 而机器人 VLA 还停在"一句短指令 → 动作"，意图带宽被压进十几个字，这正是具身智能的瓶颈。
X2Action 就是把机器人接入同一条铁律：一端对齐 LLM 的长上下文 / ICL（把上下文 X 喂进来），一端对齐可控视频生成（让模型自己生成 X）。
40.9%
起点问题：只给一句短指令"把倒下的调料瓶扶正"（约 15 字），成功率只有 40.9%。 抓哪里、朝哪个方向转、抓多深、放到哪——这些"怎么做"的信息全被语言压没了。补上这段信息，就是补上一段上下文 X。

1.2

视频 X · VideoICL

当前主攻
方向、顺序、抓取部位、目标物这些"怎么做"，视频天然就编码好了。
问题
语言表达不了的空间与操作细节（指哪个、从哪抓、朝哪转、先做哪个），在视觉参考里是天然存在的。
做法
把一段参考演示视频作为上下文喂给模型，让它照着做。训练范式采用交错 episode——同一任务的不同 episode 互为演示，避免模型用"自己的未来帧"作弊导致过拟合。
亮点
四类训练中完全未见的迁移能力被激发；对照实验证明模型是真在看视频，而非碰巧。
零样本迁移维度纯语言给视频上下文

上下文输入 & 迁移效果
最大的坑 = 训推不一致（掉点主因）。 ①帧数与间隔：训练固定 4–9 帧，推理时序列更长、间隔更大； ②物料与环境：训练用 oracle 演示，推理现场条件不同； ③视角对齐：做 crop 对齐时，头部相机位移过大导致手臂直接从画面中消失，直接掉 7 个点。 这条是我目前主攻的工程重点。
最新进展：高质量 ICL benchmark 采集完成（白背景 + 屏风标准化），两个本体各 2200 条，新链路自测正常。

2.1

Bagel2-VLA · 一步生成"模糊目标图"

已打通
问题
外部演示不总是有；而且"给什么上下文"依赖人工准备，训练与推理容易不一致。
做法
走 world model 路线：在当前观测上一步预测出一张（模糊的）未来目标图，再把它回喂给动作头当作上下文条件。推理时只走"一步"生成 goal image，动作即条件在这张图上。
亮点
